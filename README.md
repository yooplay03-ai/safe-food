# 🩺 만성질환자 맞춤형 웰니스 헬스케어 플랫폼

> **"지속 가능한 건강 데이터 관리부터 안전한 일상 식단 및 웰니스 투어까지 아우르는 만성질환자 맞춤형 케어 웹앱"**

---

## 💡 프로젝트 소개
* **개발 배경:** 고혈압, 당뇨 등 만성질환자는 꾸준한 건강 지표 모니터링과 엄격한 식단 관리가 필수적이나, 단순한 기록 방식은 지속성이 떨어짐.
* **해결 목표:** 공인된 건강검진 결과와 실시간 식단 영양 성분을 분석하고, 일상 속 힐링을 위한 맞춤형 웰니스 관광 코스를 연동하여 환자의 삶의 질 향상 도모.

---

## 🔌 연동 데이터 및 API (Data Sources)
1. **국민건강보험공단 건강검진결과 API (via CODEF)**
   * 환자의 과거 건강검진 데이터(혈당, 혈압 등) 연동 ➡️ 초기 위험군 분류 및 맞춤형 건강 목표 설정
2. **식품의약품안전처 식품영양성분 DB (가공식품 및 음식)**
   * 환자 맞춤형(저나트륨·저당류) 식단 기록 및 영양 성분 실시간 분석
3. **[한국관광공사_의료관광정보](https://www.data.go.kr/data/15143913/openapi.do)**
   * 환자 맞춤형 웰니스 힐링 코스 및 안심 의료 인프라 안내

---

## 🛠️ 주요 기능 (Core Features)
* **건강 대시보드:** 국민건강보험공단 검진 데이터 기반 건강 상태 시각화
* **식단 및 영양 분석:** 식약처 DB를 활용한 섭취 식품의 나트륨·당류 실시간 체크
* **웰니스 치유 코스:** 주변 산책로, 온천, 힐링 스팟 및 응급 의료 인프라 추천
