# 🧳 Safe-Food | 만성질환자 맞춤형 외식 안전 가이드

> **"여행지에서도, 안심하고 드세요 — 질환별 영양 기준 자동 판정 + 근처 맛집·날씨·코스까지 한 번에"**

Streamlit으로 만든 1인 웹앱입니다. 고혈압·당뇨병·신장질환처럼 숫자 기준이 명확한 질환은 실제 임상 가이드라인을 근거로 1식 기준치를 자동 계산하고, 식품의약품안전처 표준 영양성분 DB와 대조해 메뉴별로 🟢안전 / 🟡주의 / 🔴경고 배지를 매깁니다.

---

## 💡 프로젝트 소개
* **개발 배경:** 고혈압, 당뇨 등 만성질환자는 외식할 때마다 나트륨·당류·단백질 등을 일일이 따지기 어렵고, 특히 여행지에서는 정보가 더 부족함.
* **해결 목표:** 질환별 임상 가이드라인 기준치를 자동 적용해 메뉴의 안전도를 즉시 판정하고, 지역 날씨·근처 맛집·화장실·관광 코스까지 함께 안내해 여행 중에도 부담 없이 식사를 고를 수 있게 함.

---

## 🔌 연동 데이터 및 API (Data Sources)
1. **식품의약품안전처(MFDS) 식품영양성분 DB API**
   * 메뉴명으로 표준 영양성분(칼로리·단백질·나트륨·당류 등)을 조회하고, 1인분 실제 중량(`foodSize`)으로 환산해 판정
   * DB에 없는 메뉴는 수식어 제거 → 음식 종류 접미사 추출 순으로 재검색하는 폴백 로직 적용 (예: `즉석떡볶이` → `떡볶이`)
2. **기상청(KMA) 단기예보 API**
   * 위경도 → 격자좌표 변환 공식을 자체 구현해, 좌표만 있으면 어떤 지역이든 쉽게 추가 가능
   * 강수 예보 시 실내 위주 동선을 우선 안내
3. **카카오 로컬 API (Kakao Developers)**
   * 지역/관광지 근처 관광명소·음식점·화장실을 반경 검색으로 조회, `folium` 지도에 안전도 색깔 핀으로 표시
4. **Anthropic API (선택)**
   * 식약처 DB에 없는 메뉴는 AI가 대략적인 영양성분을 추정 (실측치 아님, 참고용·유료 호출임을 명시)

## 🛠️ 주요 기능 (Core Features)
* **질환별 자동 영양 기준 계산:** 고혈압(나트륨)·당뇨병(당류)·신장질환(나트륨·병기별, 단백질·체중 기반)의 하루 권장/제한량을 대한고혈압학회·대한당뇨병학회·대한신장학회·KDIGO 가이드라인 기준으로 1식 단위로 환산. 여러 질환 선택 시 가장 엄격한 기준 적용
* **메뉴 검색 & 안전성 판정:** 메뉴명을 검색하면 식약처 DB와 대조해 🟢안전/🟡주의/🔴경고 배지와 세부 수치를 카드로 보여주고, 검색 결과 중 가장 무난한 선택을 하이라이트
* **AI 영양 추정 (선택):** DB에 없는 메뉴는 Anthropic API로 대략적인 수치를 추정 (실측 카드와 시각적으로 구분)
* **키워드 기반 주의 안내:** 염증성장질환(IBD)·과민성대장증후군(IBS)·역류성식도염·통풍처럼 숫자 기준이 애매한 질환은 메뉴명 키워드로 주의 문구 제공 (IBD는 관해기/활성기 상태도 반영)
* **알레르기 체크:** 갑각류·견과류·우유·밀(글루텐)·계란 등 선택 시 메뉴명 키워드로 알레르기 주의 표시
* **건강검진 수치 자가 입력:** 혈압·공복혈당·총콜레스테롤·BMI를 입력하면 임상 기준과 비교해 정상/주의/위험 표시 (자동 연동 아닌 자가 입력, 참고용)
* **직원에게 물어볼 체크리스트 & 무난한 메뉴 추천:** 식약처 DB 매칭 여부와 무관하게 질환별로 항상 제공
* **날씨 연동:** 선택 지역의 오늘 기온·강수형태·강수확률을 표시
* **근처 관광지·맛집·화장실 지도:** 카카오맵 기준 실좌표로 반경 내 장소를 지도에 표시
* **오늘의 코스 만들기:** 관광지 2~4곳을 고르면 최근접 이웃 방식으로 방문 순서를 짜고, 각 장소 근처 식당을 자동 추천 (직선거리 기준 MVP)

## ⚠️ 참고 사항
* 모든 안전도 판정은 **표준 레시피 기준 추정치 / 참고용 정보**이며, 실제 조리법·재료에 따라 다를 수 있습니다. 정확한 개인별 식단·진단은 반드시 의료진·영양사와 상담하세요.
* AI 추정치는 **실측값이 아닙니다.**
* 카카오맵 기반 장소 정보(특히 화장실)는 공식 등록 데이터가 아니라 태그 기준이라 일부 누락될 수 있습니다.
* 코스 동선은 직선거리 기준이며, 실제 도보/차량 경로와 다를 수 있습니다.

## 🚀 실행 방법 (Local Setup)

```bash
# 1. 가상환경 생성 & 활성화
python -m venv venv
venv\Scripts\activate       # Windows
# source venv/bin/activate  # macOS/Linux

# 2. 패키지 설치
pip install streamlit requests folium streamlit-folium

# 3. API 키 설정
# .streamlit/secrets.toml.example 을 복사해 .streamlit/secrets.toml 로 만들고
# 아래 키를 발급받아 채워넣으세요 (모두 선택 사항이며, 없어도 앱은 실행됩니다)
#   - MFDS_API_KEY       : 공공데이터포털 > 식품의약품안전처 식품영양성분 DB
#   - KMA_API_KEY        : 공공데이터포털 > 기상청 단기예보 조회서비스 (Decoding 키)
#   - KAKAO_API_KEY      : Kakao Developers > REST API 키 (카카오맵 사용 설정 필요)
#   - ANTHROPIC_API_KEY  : console.anthropic.com (선택, AI 영양 추정용)

# 4. 앱 실행
streamlit run app.py
```

> `secrets.toml`은 `.gitignore`에 포함되어 있어 커밋되지 않습니다. 키를 입력하지 않아도 사이드바에서 직접 입력해 사용할 수 있습니다.
